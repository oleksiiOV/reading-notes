## What is the purpose of CSS?

CSS (Cascading Style Sheets) is used to style and lay out web pages. It separates the document content (HTML) from the presentation (colors, fonts, and layouts), making websites easier to maintain.

## What are the three ways to insert CSS into your project?

1. External CSS

2. Internal CSS

3. Inline CSS

## Write an example of a CSS rule that would give all `<p>` elements red text.

<code>
p {

     color: red;
}
</code>
