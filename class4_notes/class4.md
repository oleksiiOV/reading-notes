## What is HTML and why do we use it?
HTML (HyperText Markup Language) is the standard language used to create and structure content on the web. We use HTML to define the structure of a webpage, such as headings, paragraphs, links, images, and sections, so browsers know how to display the content.

## What are the 3 main parts of an HTML element?
1. Opening tag  
2. Content  
3. Closing tag  

## What is it called when you give an element extra information?
Giving an element extra information is done using **attributes**.

## What is a semantic element?
A semantic element is an HTML element that clearly describes its meaning and purpose in the webpage structure, both to the browser and to developers (e.g., `<header>`, `<nav>`, `<article>`, `<footer>`).
