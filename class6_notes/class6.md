## What are variables in JavaScript?

Variables are containers used to store data values  that can be used and changed throughout the program.

## What does it mean to declare a variable?

To declare a variable means to create it using the keywords `let`, `const`, or `var`.

## What is an “assignment” operator, and what does it do?

The assignment operator is the equals sign (=), it assigns a value to a variable.

> let score = 10;

## What is information received from the user called?

Information received from the user is called input. In web development, this usually comes from text fields, buttons, or prompts.
